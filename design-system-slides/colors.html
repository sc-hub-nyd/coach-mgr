04 / COLOR SYSTEM

色名ではなく、役割で定義する

部品はテーマ固有色を直接参照せず、意味を持つカラーAPIだけを参照する。

01
THEME
チームテーマ

Field Green、Midnight Pitch、High Visibilityなどの基礎色を定義する。

↓
02
SEMANTIC
意味トークン

`--color-action`、`--color-surface`のように用途を抽象化する。

↓
03
COMPONENT
共通部品

フォーム、名簿、カード、モーダルが同じ意味の色を再利用する。

表面
canvas / surface / border
画面背景、カード、モーダル、区切り。情報階層を色数ではなく明度差でつくる。
文字
text / text-muted
本文、補足、メタ情報。文字色と背景色を必ず対として指定する。
主操作
action / action-hover
保存、追加、切替。重要な動線へ限定し、過度なアクセント使用を避ける。
状態
success / warning / danger / info
出欠、同期、警告、通知。色だけでなくアイコン・状態テキストを併用する。
視認性
focus / shadow-focus
キーボードフォーカス。テーマ変更時も一貫して明確な操作位置を示す。
効用：テーマ追加は基礎色の差替えだけで完結し、部品の色指定を変更しない。
