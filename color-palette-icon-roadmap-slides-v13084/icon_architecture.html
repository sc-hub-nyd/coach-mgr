06 / ICON ARCHITECTURE

アイコンは、4層で意味を分担する

一つのパックにすべてを任せない。概念に最も近い表現層を選び、チーム固有性と業務の分かりやすさを両立する。

似た形ではなく、
近い意味を選ぶ。

アイコンは装飾ではなく、操作・状態・文脈を補う部品。単一のTabler体系を使い、意味の重複や誤読を避ける。

02可視テキストラベル

LAYER 1
Tabler Icons
.ti .ti-*
主要ナビ、得点、アシスト、ピッチ、経路、コーン、ラダーをローカル配信で提供。
LAYER 2
可視テキストラベル
visible label
画面名、操作名、状態をアイコンと併記し、意味を一意にする。
LAYER 3
絵文字
rank only
ランキング順位などの非操作的な補助表示。主要な操作や重要な状態には使わない。
LAYER 4
Canvas描画
tactics board
選手位置、パス、ドリブル、エリア。アイコンではなく、戦術表現そのものを担当。
アイコン、ラベル、ARIA、Canvas表現は、同じ意味を伝える。

ラベルがある操作のアイコンは装飾として扱い、単独操作には日本語の`aria-label`を与える。色や形だけで状態を伝えない。
