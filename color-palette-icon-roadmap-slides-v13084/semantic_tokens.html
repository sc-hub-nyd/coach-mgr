02 / SEMANTIC COLOR SYSTEM

部品は、色名でなく役割を参照する

チームカラーを変えても、「主操作」「注意」「文字」の意味が崩れないCSS API。

HEX直書きでは、
テーマ変更に
耐えられない。

画面ごとに赤・緑・白を指定すると、ライト／ダークやチーム色変更で整合性を失う。

STEP 1

テーマプリミティブ

テーマ生成器が色値を差し替える層。

--theme-primary
--theme-surface
--theme-text
--theme-focus
STEP 2

セマンティックトークン

部品に渡す、変わらない役割名。

--color-action
--color-surface
--color-text
--color-danger
STEP 3

コンポーネント

部品の目的に合わせて役割だけを消費。

主操作ボタン
カード・入力面
成功・警告・エラー
フォーカス表示

実装例

同じ部品CSSを、すべてのチーム色・表示モードで再利用する。

.c-button--primary {
  background: var(--color-action);
  color: var(--color-text-on-action);
}
結果： チーム色を変えても、部品の意図・前景色・コントラスト判定が一緒に追随する。
ルール：新しい部品はチームのHEX値を直接参照せず、`--color-*`のセマンティックトークンを使用する。
