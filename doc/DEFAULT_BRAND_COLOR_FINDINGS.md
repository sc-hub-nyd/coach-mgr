# 既定ブランドカラー決定記録

確認日：2026-08-18

## 目的

CoachMgrは、未設定チームでも一貫した主操作・選択状態・フォーカス表示を提供し、利用者が任意のチームカラーへ安全に変更できるよう、汎用的な赤系の既定種色を採用する。本記録は、特定クラブや外部サイトのブランドを根拠にせず、アプリの可読性、操作識別性、動的テーマ生成に基づく決定内容を残す。

## 決定内容

| 項目 | 決定 |
|---|---|
| 既定ブランド種色 | `#EF3340`。未設定チームの初期値として使用する。 |
| 動的テーマ | 種色を`color-theme-service.js`へ渡し、light/dark別の主操作、前景、surface、borderを生成する。 |
| チームカラー変更 | 維持する。利用者の選択色を種色として保存し、既存チームの保存値を上書きしない。 |
| 状態色 | success / warning / danger / infoをブランド色と独立した意味ロールとして維持する。 |
| アイコン | SVGとTabler Iconsは`currentColor`とセマンティック前景トークンを通じてテーマへ追従させる。 |

## 適用原則

`#EF3340`は完成済みのコンポーネント色ではなく、生成器への入力値である。実装では主操作、主操作上の文字、選択面、境界、フォーカスを同一の赤で固定せず、セマンティックトークンを介してlight/darkと利用者のチームカラーに追従させる。

> 既定ブランド種色は、初期状態を整えるためのフォールバックである。既存チームの保存済み種色を無断で置換してはならない。

カラー変更時は、動的テーマの代表種色群に対するコントラスト検証、P33のアーキテクチャ契約、P34の動的テーマ契約、P47の品質シナリオを通過しなければならない。
