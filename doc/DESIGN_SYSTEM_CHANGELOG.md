# CoachMgr デザインシステム変更履歴

この文書は、アプリ機能の更新履歴とは別に、再利用可能なデザインシステム契約の追加・変更・非推奨化を追跡する。画面固有の見た目だけを変えた変更は記録しない。トークン、共通部品、アイコン体系、アクセシビリティ、品質ゲート、PWA資産へ影響する変更を記録する。

## v1.30.85 — 2026-08-20

| 領域 | 変更 | 移行・互換性 | 検証 |
|---|---|---|---|
| カラー | `--color-status-*`、通知、オーバーレイ、toastの役割トークンを追加した。ダッシュボードの主要なブランド・予定・結果・進捗表現をセマンティックカラーへ移行した。 | 旧`--primary`系の参照は段階移行とし、新規部品では使用しない。 | P34、P44、P45、デザインシステム監査 |
| 状態部品 | `c-notice`、`c-state-icon`、状態別toast、入力invalid、button disabled/loading、状態ラベルの押下状態を標準化した。 | `showToast(message)`は従来どおり使える。第2引数で`type`と`duration`を任意指定できる。 | P45、P46、P47 |
| アクセシビリティ | トーストをlive region、確認モーダルを名前・説明付きdialogへ更新した。 | 既存DOM IDと既存の確認APIは維持する。 | P45、P47 |
| アイコン配信 | 実行時144クラスのTablerサブセットを採用し、PWA precacheをフル資産から切り替えた。 | 新しい`ti-*`を追加・削除するPRでは、サブセットの再生成が必須。 | P42、サブセット評価 |
| 高密度検証 | 12名、長い日本語名、未回答、複数操作を含む固定フィクスチャと視覚回帰プロトコルを追加した。 | 実ユーザーデータを上書きしない。 | P46、P47、手動プロトコル |
| 統制 | デザインシステム監査、PRテンプレート、変更履歴、品質プロトコルを追加した。 | UI変更はテンプレートと品質ゲートを通す。 | P44、P47、`git diff --check` |

## 記載規約

| 項目 | 必須記載内容 |
|---|---|
| バージョン | アプリ版、日付、変更したデザインシステム領域 |
| 変更 | 新しい契約、変更した契約、非推奨化、削除予定 |
| 移行 | 影響する画面、DOM・イベントの互換性、移行期限、例外 |
| 検証 | 追加・変更した契約テスト、テーマ・レスポンシブ・PWA確認 |
| 解除条件 | 一時的例外がある場合、その削除条件と担当フェーズ |
