# CoachMgr アイコンシステム

**適用対象：CoachMgr PWAのナビゲーション、共通操作、試合・練習・選手管理、保護者画面、作図補助UI、PWA**

## 1. 方針

CoachMgrは、アプリ内のUIアイコンを**ローカル配信のTabler Icons 3.46.0**へ統一する。別のカスタムSVG資産は保持せず、アイコン体系を一つに絞ることで、意味の一貫性、テーマ追従、PWAキャッシュ管理、将来の保守性を確保する。

> アイコンはテキストを置き換えない。操作名、選択肢、状態は可視ラベル・ARIA・色・フォーカスと組み合わせて伝える。

## 2. 実装規約

| 項目 | 規約 |
|---|---|
| 配信 | `assets/vendor/tabler-icons/`からサブセットCSS・WOFF2をローカル配信する。外部CDNへ依存しない。 |
| マークアップ | `<i class="ti ti-{name}" aria-hidden="true"></i>`を使用する。ラベル付き操作ではアイコンを装飾扱いにする。 |
| 単独操作 | 可視ラベルがないボタンには日本語の`aria-label`と`title`を付ける。 |
| 色 | `.ti`は`currentColor`を継承する。ブランド・状態色は`c-tabler-icon--*`とセマンティックトークンを使用し、HTMLへ具体色を固定しない。 |
| PWA | TablerサブセットCSS・WOFF2をService Workerのprecacheへ含める。未使用のフルフォントや別アイコン資産は含めない。 |
| 追加 | 新しい`ti-*`を使う前にサブセット内の定義を確認する。未収録ならサブセット生成手順を実行し、P42を通過させる。 |

## 3. ナビゲーションの標準対応

| 画面または操作 | Tablerクラス | 可視ラベル |
|---|---|---|
| ホーム | `ti-home` | ホーム |
| 選手管理 | `ti-users` | 選手管理 |
| メニュー／戦術（モバイル二択） | `ti-soccer-field` | メニュー／戦術 |
| 試合記録 | `ti-trophy` | 試合／試合記録 |
| 練習管理 | `ti-calendar` | 練習／練習管理 |
| メニュー管理 | `ti-book-2` | メニュー／メニュー管理 |
| 戦術管理 | `ti-route` | 戦術／戦術管理 |
| その他 | `ti-dots` | その他 |
| 設定 | `ti-settings` | 設定 |

コーチ用モバイルボトムナビでは、試合／練習とメニュー／戦術を二択トリガーとして表示する。試合／練習には`ti-ball-football`、メニュー／戦術には競技全体を示す`ti-soccer-field`を使う。トリガーのタップ後は、共通ボトムシート内で各画面名と説明を伴う選択肢を提示する。

## 4. アクセシビリティと検証

アイコンだけで状態や操作を表現しない。選択中のボトムナビは選択面、ブランドライン、可視ラベル、`active`状態を同期する。二択シートは`role="dialog"`、見出し、説明、フォーカストラップ、トリガーへのフォーカス復帰を備える。

アイコン体系を変更した場合は、P33、P42、P47、P53、P55、P56および全契約テストを通過させる。カスタムSVGの資産・CSSマスク・実行時HTML・Service Worker参照を再導入してはならない。
