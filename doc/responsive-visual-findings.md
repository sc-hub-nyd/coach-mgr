# レスポンシブ視覚確認の所見

320px幅のコーチダッシュボードでは、セットアップ・優先行動カード・下部ナビゲーションは読みやすく、主操作も画面内に残っている。一方で、ページ最下部に横スクロールバーが現れており、画面全体が横方向へ溢れている。

320px幅のField Companionでは、試合時計、スコア、6つの即時記録操作、下部ナビゲーションは可視であり、操作ボタンの高さも実用的である。ただし横スクロールバーが存在し、上部ユーティリティ操作（モード・同期・更新表示）が本文幅を超えている。横溢れは試合当日操作帯そのものではなく、グローバルトップバーとその横並び状態に起因する。

320px幅の設定画面では、設定ハブと表示設定は一列化されて可読性を保っているが、ページ最下部の横スクロールバーが残る。これは繰り返し追加フォームの横並びと、トップバーの合計幅が影響している。

768px幅のField Companionでは、試合前チェックは二列、操作帯は5列、名簿は二列で意図どおり配置され、横溢れはない。したがって、修正対象は主に390px以下のグローバルトップバーと、320px設定画面の追加フォームである。

修正後の320px幅コーチダッシュボードでは、コーチ専用ランキング行も一列化され、ページ最下部の横スクロールバーは表示されない。修正後の320px幅Field Companionでも横スクロールバーは消え、時計・試合前チェック・2列の主要記録操作・下部ナビゲーションが可視領域に収まっている。詳細画面では更新履歴ボタンを省略し、戻る操作と試合当日の主要機能を優先している。
