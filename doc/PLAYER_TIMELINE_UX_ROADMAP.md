# 選手タイムライン UX 改善ロードマップ

## P0 — 迷子にしない

P0は、既存の年表構造を変えずに、開閉・検索復帰の位置を理解し続けられるようにする。対象は、現在地パンくず、検索結果から戻った地点の強調とライブ通知、検索結果へ戻る操作、学年・月・記録の開閉状態とキーボードフォーカスの復元である。検索タブはWAI-ARIAタブとしてArrowLeft、ArrowRight、Home、Endを提供する。動きを減らす設定では、強調は色・境界・テキストだけで示す。

P0では、年度横断データの集約、表示する記録件数、権限、既存の試合詳細遷移を変更しない。契約テストでは状態の保存・復元、タブキーボード操作、現在地通知、保護者モード、Tabler限定、縮退モーションを検証する。

## P1 — 月をたどりやすくする

P1は、月を開く前後の判断と連続閲覧を速くする。月フラッグには種別ごとの件数を加え、開いた月の先頭に「今月のひとこま」と最新の次の一歩を表示する。月詳細の末尾には前後の記録月への操作を置き、空月を飛ばして次の実在記録へ移動する。検索画面には結果件数、条件チップ、クリア操作を表示する。

P1では、月の全件を自動展開しない。月サマリーは新しいデータを保存せず、既存のノート、観察、試合、練習を集計して表示する。モバイルでは前後月操作を44px以上のタップ領域として、ボトムナビと重ならない位置に置く。

## P2 — 役割に合わせる

P2は、年度横断の同一選手ID監査後に進める。保護者には今月のひとこま、最新の次の一歩、更新順の足あとを優先し、コーチには前回検索条件、記録追加、未記録月への入口を優先する。学年見出しでは、試合、練習、メモの比率と代表テーマを俯瞰できるようにする。

P2では、現学年からの機械的な逆算だけで過去の学年を確定しない。年度ワークスペースをまたぐ同一選手ID、学年、活動記録を監査してから横断表示を有効にする。
