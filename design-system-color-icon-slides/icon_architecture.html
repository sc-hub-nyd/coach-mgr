01 / ICON ARCHITECTURE

4層で、意味を使い分ける

アイコンパックは万能ではない。概念に最も近い表現層を選び、画面・作図・テーマの整合を保つ。

意味は
一つずつ
担当させる。

同じ操作に複数の記号を競合させない。迷ったときは、台帳の第一候補・可視ラベル・Canvas表現を確認する。

LAYER 1
Tabler Icons
.ti .ti-*
主要ナビゲーション、業務操作、サッカー補助語彙を単一のローカルアイコン体系で提供。
LAYER 2
Canvas描画
tactics board
選手の位置、パス、ドリブル、エリア。記号ではなく、戦術表現そのものを描く。
LAYER 3
絵文字
rank only
順位のような、非操作的で補助的な情報。主要操作を絵文字だけで表さない。
LAYER 4
テキストラベル
visible label
アイコンだけでは伝わりにくい操作名・状態・選択肢を常時明示する。

選定規則： ローカルTabler Iconsを単一のアイコン体系とする。アイコンはラベルを置き換えず、色だけで状態を伝えない。
