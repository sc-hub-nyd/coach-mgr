# CoachMgr UI一貫性監査 — 対象・評価基準

## 監査対象

本監査は、PC・モバイルのアプリシェル、サイドバー／ボトムナビ、ボタン、通知・トースト、カード、一覧行、バッジ、モーダル、フォーム、空状態、ローディング、危険操作を対象とする。主要画面はダッシュボード、試合、練習、メニュー、戦術、選手、設定、および横断モーダルとする。

## 評価基準

| 観点 | 合格基準 |
|---|---|
| 色の意味 | 成功・警告・危険・情報・主要操作は、同じ意味を同じ役割トークンで表現する。肯定的な通知内へ危険・ブランドprimaryを混在させない。 |
| 状態変化 | 通常、hover、focus-visible、active、disabledで意味が連続し、汎用規則が局所的な意味規則を上書きしない。 |
| 形状と密度 | 同じ操作階層の高さ、角丸、余白、影、アイコンとラベルの関係を揃える。密度の高いカードでも内容幅へ不意に縮まない。 |
| 階層 | 主操作は一画面・一領域で明確に一つとし、補助・危険操作と色、面、配置で区別する。 |
| アクセシビリティ | 44px以上の操作領域、キーボードfocus-visible、disabledの非操作性、アイコン操作の名前、色だけに依存しない状態表示を維持する。 |
| テーマ耐性 | light/darkと任意チームカラーで直接指定色に依存せず、セマンティックトークンから解決する。 |

## 優先度

| 優先度 | 判断基準 |
|---|---|
| P0 | 意味が逆転する、操作不能、危険操作と通常操作の誤認、アクセシビリティ障害。 |
| P1 | 明らかな色役割の衝突、同じ操作群の大きさ・形状不一致、主要フローの視覚的違和感。 |
| P2 | 画面間の影・角丸・余白の僅かな不統一、改善余地のある密度。 |
| P3 | 現行設計で許容できる軽微な視覚調整、将来の整理候補。 |

## 実画面確認の記録

- デスクトップ・ダッシュボード（保護者モード、空状態）を確認した。トップバー、サイドバー、カード、空状態、ランキング、同期表示を対象にした。
- 空状態では「試合を追加」が予定と直近試合の双方に現れるため、同じ操作の重複露出と主操作の階層は詳細データ状態でも確認対象とする。
- 更新通知の検証用表示は解除し、通常画面状態へ戻した。

コーチモード切替モーダルを確認した。危険性のない切替導線として、通常の取消操作と強調された解除操作が分離され、スクリーン上で意図が判別できた。パスコードを持たない監査セッションでは解除を試行せず、コーチ専用画面の実データ状態は静的CSS・テンプレート・既存契約を中心に確認する。

試合記録および練習管理の保護者モード空状態を確認した。両画面は検索・絞り込み・並び替えの操作列と破線の空状態surfaceを共通に用いており、少なくとも空状態の情報構造と角丸・罫線・余白は整合している。コーチモードでは追加操作と実データカードが現れるため、当該領域は実装CSSと既存の画面証跡を併用して評価する。

ダーク表示の練習管理空状態を確認した。画面構造、角丸、検索・絞り込み操作の配置はライト表示と連続している。一方、空状態の補足文、破線罫線、検索プレースホルダーは背景との明度差が小さく見えるため、実効色のコントラストを数値確認する候補として記録した。

ダーク表示で実効色を確認したところ、選択中ナビゲーションは`rgba(242, 57, 50, 0.08)`、保護者モード切替は固定の緑系、同期ドットは固定の緑系を使用していた。これらはテーマ・チームカラーの意味トークンではなく具体色に解決されるため、チームカラー変更時の一貫性を損なう候補として扱う。

ライト表示の練習空状態は、見出しとsurfaceの実効コントラスト比が14.56:1、補足文とsurfaceが5.54:1であり、本文テキストの基準を満たすことを確認した。ダーク表示も同じ計測手順で確認する。

ダーク表示の練習空状態は、見出しとsurfaceの実効コントラスト比が19.27:1、補足文とsurfaceが7.86:1であり、視覚的に控えめではあるが本文テキストの基準を満たした。空状態の可読性は今回の改善対象には含めない。
