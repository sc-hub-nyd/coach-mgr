# CoachMgr コンポーネント標準化監査 — 波F

**リリース:** v1.30.65  
**実施日:** 2026-08-19  
**対象ブランチ:** `feat/label-shape-unification`

## 実施範囲

波Fでは、作図や試合記録の機能専用の座標・Canvas描画を維持したまま、残存していたカード周辺UI、開示コンテンツ、ミニピッチプレビュー、試合ピリオド編集を共通部品へ移行した。静的な余白・寸法については、対象画面からインライン指定を外し、局所的な`!important`依存も削減した。

| 区分 | 実施内容 | 正規部品・契約 |
|---|---|---|
| F0 | 未参照の`u-ext-171`〜`173`を削除 | P35でCSS選択子と実行時クラスの再導入を禁止 |
| F1 | 練習、ライブラリ、戦術の詳細開示を統一 | `c-content-disclosure`、`c-content-disclosure-list` |
| F2 | 練習、ライブラリ、戦術のCanvasプレビューを統一 | `c-media-preview` |
| F3 | 試合ピリオドの得点、配置、スコア、保存導線を統一 | `c-period-editor`、`c-score-stepper` |
| F4 | ライブラリ・戦術カードとカテゴリ見出しを統一 | `c-library-card`、`c-tactic-card`、`c-section-group` |
| F5 | ピリオド編集の静的なミニピッチ寸法・保存余白を移行 | `c-period-editor__mini-pitch`、`c-period-editor__save-wrap` |
| F6 | 旧Canvasホバー規則を共通プレビュー規則へ置換 | 関連する`!important`を1件削除 |

## 旧CSSの削除確認

`u-ext-150`〜`158`、`159`〜`162`、`163`〜`167`、`171`〜`173`、`183`、`185`〜`190`、`191`〜`201`、およびピリオド編集の`u-ext-78`〜`98`・`104`〜`105`・`107`〜`109`・`112`〜`114`について、HTML、JavaScript動的テンプレート、共通CSSの実行時参照がゼロであることを確認してから定義を削除した。

Canvas上の選手座標、ドラッグ、ピッチ描画、動画・作図への遷移を表す実行時値は、インライン値または機能専用クラスとして保持した。静的な幅、余白、開示状態、カード構造だけを共通部品へ移行している。

## 保持した機能契約

| 機能 | 保持方法 |
|---|---|
| 練習メニュー | 編集、作図、削除、アニメーション拡大の既存`data-*`属性とイベントセレクタを維持 |
| ライブラリ・戦術 | 作図遷移、編集、削除、ライブラリ追加、Canvas描画IDを維持 |
| ピリオド編集 | 得点・アシスト、スコア加減算、配置割当、保存ID、保護者閲覧表示を維持 |
| モバイル操作 | P38の44px操作領域、権限制御、戻る文脈復元を継続検証 |
| 再発防止 | P35へF0〜F4の共通部品存在・利用契約と旧クラス再導入禁止を追加 |

## 継続方針

今回のF5・F6は、変更対象のカード、プレビュー、ピリオド編集に限った局所的な整理である。残るインライン指定は、Canvas座標・進捗幅・テーマ値といった実行時値を除外して、画面ごとに静的装飾だけを分類する。残る`!important`も同様に、同一部品の規則を同一CSS層へ寄せてから、視覚回帰確認を伴って削減する。一括削除は行わない。
