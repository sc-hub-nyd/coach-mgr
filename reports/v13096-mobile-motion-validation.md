# v1.30.96 モバイル操作アニメーション実装・検証記録

**対象バージョン:** `v1.30.96` / `coachmgr-v206`
**実施日:** 2026-08-20
**対象範囲:** モバイルボトムナビ、その他ボトムシート、モバイルコンテキストバー、モーダル共通操作

## 実装概要

v1.30.96では、チーム共有で合意した「短く、意味があり、止められる動き」を、既存のVanilla JS/CSS構成を崩さずに実装した。画面全体を動かす遷移演出は導入せず、タップ、選択、モーダル展開、コンテキストバーの表示といった状態フィードバックへ対象を限定している。

| 領域 | 実装内容 | 互換性・アクセシビリティ |
|---|---|---|
| モーション体系 | `--duration-micro: 80ms`、既存の140ms・200ms、`--duration-sheet: 260ms`、`--duration-sheet-close: 180ms`を定義した。 | `prefers-reduced-motion` とアプリ内の動きを減らす設定で全時間を1msに縮退する。 |
| ボトムナビ | 選択タブは`--color-surface-selected`によるLiquid Lens面、ブランドライン、強調アイコン・太字ラベルへ移行した。 | 既存の4/5タブ、チームカラー、light/dark、ARIAラベル、44px以上の親指操作領域を維持する。 |
| 押下反応 | `is-pressing`により80msの控えめな沈み込みを表示し、選択時の余韻は一度だけで終了する。 | 無限ループ、点滅、隣接タブへ広がる演出を導入していない。 |
| その他ボトムシート | 開く時は260ms、閉じる時は180ms。`is-closing`中は`aria-expanded`を即時にfalseへ同期する。 | Escape、オーバーレイ、閉じるボタン、ルート遷移を維持し、閉じた後はトリガーへフォーカスを戻す。 |
| コンテキストバー | 詳細画面で200ms表示、一覧へ戻る時は140msで退場する。 | ルートと戻るボタンの状態更新を遅延させず、動きを減らす設定では移動を抑止する。 |
| モーダル共通操作 | 開閉状態、最前面モーダルのTab循環、Escape閉じを共通化した。 | 既存の`openModal`呼び出しとDOM IDを保持する。 |

## 契約テストの拡張

P47は、モーショントークン、動きを減らす設定、Liquid Lens選択面、ボトムシートの開閉トークンを保護する。P54は、その他タブの展開状態、ブランドライン、閉じるモーション、フォーカス復帰、Tab循環を保護する。P49のService Worker世代期待値を`coachmgr-v206`へ同期した。
