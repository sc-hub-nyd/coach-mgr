# CoachMgr 静的インライン装飾分類台帳

## 目的

インライン指定を一括削除せず、機能上必要な動的値とCSS部品へ移せる静的装飾を分離する。

| 区分 | 例 | 扱い |
|---|---|---|
| 許容する動的値 | Canvas座標、ドラッグ位置、進捗幅、チームテーマ変数 | インラインまたはCSS変数として維持。生成元を明確化する。 |
| 静的レイアウト | 固定幅、余白、flex/grid、静的な表示切替 | `l-*`または`c-*`修飾子へ移行する。 |
| 静的装飾 | 色、文字サイズ、アイコン色、境界 | トークンと共通部品へ移行する。 |
| 一時状態 | 表示・非表示、選択、警告 | `hidden`・`is-*`・ARIA属性を優先し、既存イベントとの整合を確認する。 |

## 波Hでの適用

試合ピリオドの交代表示、保存余白、フォーメーション編集行、対戦相手成績、試合一覧の参加者開示では、静的な余白・色・レイアウトを共通部品へ移した。PKの成功・失敗マークやピッチ上の位置など、データにより変わる値は保持する。

## 検証

静的指定を移す前後で、DOM ID、`data-*`属性、イベント委譲、モバイル幅、ライト／ダークテーマを確認する。`node tests/run-contract-tests.mjs`、`node tests/run-responsive-validation.mjs`、`bash scripts/audit-legacy-css.sh`、`git diff --check`を通過条件とする。
