# 作図アイコン識別性改善 実装記録

**対象バージョン**: v1.30.84
**日付**: 2026-08-20（JST）

## 実装範囲

D1〜D5として、作図ツールドックの意味表現、タッチ端末での可読性、選択状態のアクセシビリティ、アイコン台帳、契約テストを更新した。

| 項目 | 実装内容 |
|---|---|
| D1 | 移動を`ti-route`、パスを`ti-arrow-right-dashed`、ドリブルを`ti-arrow-zig-zag`、コーンを`ti-cone`、ラダーを`ti-ladder`へ変更した。 |
| D2 | すべての作図ツールに日本語の可視ラベルを常時表示し、デスクトップ幅68px・モバイル幅64pxのツールドックに更新した。 |
| D3 | `aria-label`と`aria-pressed`を各ツールへ設定し、選択状態を背景、アイコン、ラベル、可視フォーカスで同期した。 |
| D4 | `ICON_SYSTEM.md`へ4層の役割分担、作図アイコン台帳、禁止代替、変更レビュー規約を追加した。戦術作図への入口は`ti-soccer-field`、選手配置は`ti-shirt-sport`へ更新した。 |
| D5 | P43を追加し、意味に合うアイコン、常時ラベル、ARIA、モバイル幅、旧アイコン再導入禁止、戦術導線を検証する。 |
