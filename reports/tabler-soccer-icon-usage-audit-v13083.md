# Tablerサッカー関連アイコン利用・作図識別性監査

**対象**: CoachMgr v1.30.83  
**監査日**: 2026-08-20（JST）  
**対象ライブラリ**: Tabler Icons Webfont 3.46.0（ローカル同梱）

## 結論

今回のFont Awesome移行では、**得点・アシスト・走行・強化テーマ・試合結果**にサッカー文脈のTablerアイコンを実用的に導入できています。一方で、Tablerに存在する**ピッチ、スポーツシャツ、スプリント、到達点、コーン、ラダー、経路**などの語彙は、まだ画面や作図ツールへ十分に活用されていません。

> 最も優先すべき問題は、作図ツールバーの「パス」「ドリブル」「コーン」「ラダー」です。現在のアイコンはそれぞれ**三点リーダー、心電図、小三角、ハンバーガーメニュー**に見えるため、サッカーの作図操作を直感的に示せていません。さらにラベルは通常時に非表示で、選択中だけ表示されます。タッチ端末ではホバー説明も使えないため、未選択の状態で意味を見分けにくい構造です。

## 調査したTablerのサッカー・作図関連語彙

Tabler Icons公式カタログは、同一の24×24グリッドと原則2pxストロークで設計されたアイコンセットとして説明しています。CoachMgrが固定採用している3.46.0では、サッカー固有のボール・ピッチ・スポーツシャツ・シューズに加え、走行、経路、矢印、コーン、ラダーなどを組み合わせて、試合記録と戦術作図の双方を表現できます。[1]

| 分類 | Tablerアイコン | CoachMgrでの推奨意味 | 3.46.0での状況 |
|---|---|---|---|
| ボール／得点 | `ti-ball-football` | 得点、ボール配置、試合の識別 | 利用中 |
| ピッチ／戦術盤 | `ti-soccer-field` | 戦術画面、戦術テンプレート、ピッチ設定 | 未利用 |
| 選手配置／ユニフォーム | `ti-shirt-sport` | 選手配置、チーム編成、ユニフォーム設定 | 未利用 |
| アシスト | `ti-shoe` | アシスト、足元のプレー | 利用中 |
| 走行／スプリント | `ti-run` / `ti-run-sprint` | 作図を開く、走力、スプリント分析 | 前者のみ利用中 |
| 目標／到達点 | `ti-target` / `ti-target-arrow` | 強化テーマ／目標、到達点・狙い | 前者のみ利用中 |
| 移動経路 | `ti-route` / `ti-route-alt-right` | 選手移動、経路操作 | 未利用 |
| パス | `ti-arrow-right-dashed` | 点線の直線パス | 未利用 |
| ドリブル | `ti-arrow-zig-zag` / `ti-scribble` | ジグザグまたは曲線のドリブル | 未利用 |
| 練習器具 | `ti-cone` / `ti-ladder` | コーン、ラダー配置 | 未利用 |
| 大会／勝利 | `ti-trophy` | 試合結果、順位、達成 | 利用中 |
| コーナー／節目 | `ti-flag` | コーナー、目標、開始点 | 利用中（限定的） |

`ti-whistle`、サッカーの警告・退場を直接意味する専用の審判カードは、**同梱している3.46.0 Webfontの定義に存在しません**。`ti-cards`は提供されますが、サッカーのイエロー／レッドカードを指す図形ではありません。そのため、審判操作を将来追加する場合は、無関係な汎用アイコンで代用せず、既存のカスタムSVGレイヤーで意味を確保するべきです。

## 今回の変更での活用状況

リポジトリ内のHTMLおよび動的生成JavaScriptを集計すると、利用中のTablerクラスは**138種類**です。そのうちサッカー文脈を直接担うアイコンは、基本業務画面では積極的に使われています。以下の数は、ソースコードに記述されたテンプレート／動的生成箇所の件数であり、実行時に画面へ出る個数ではありません。

| アイコン | 出現数 | 主な利用箇所 | 評価 |
|---|---:|---|---|
| `ti-ball-football` | 20 | 得点、試合、チーム名、作図のボール | **積極利用**。目的と形状が一致 |
| `ti-target` | 16 | チーム・個人の強化テーマ、PKキッカー情報 | **積極利用**。目標・焦点として一貫 |
| `ti-trophy` | 11 | 今季成績、試合結果、ランキング | **積極利用**。成果の意味が明確 |
| `ti-run` | 10 | 作図を開く、練習・選手の活動 | 利用中。ただし「作図を開く」の代表にはやや抽象的 |
| `ti-shoe` | 8 | アシスト、得点との併記 | **積極利用**。得点アイコンとの対比も良好 |
| `ti-flag` | 1 | 初期設定のチーム情報 | 限定的。コーナー／節目には未展開 |
| `ti-soccer-field` | 0 | — | 未活用。戦術への入口に適する |
| `ti-shirt-sport` | 0 | — | 未活用。配置・ユニフォームに適する |
| `ti-run-sprint` | 0 | — | 未活用。走力・加速の分析に適する |
| `ti-target-arrow` | 0 | — | 未活用。戦術の「狙い」「到達点」に適する |
| `ti-route` / `ti-cone` / `ti-ladder` | 0 | — | 未活用。作図ツールで優先度が高い |

したがって、評価は**「移行の核となるサッカー語彙は活用済みだが、Tablerを選んだ利点を作図・戦術体験へ展開し切れていない」**です。Font Awesomeの機械的な置換としては成功していますが、Tabler固有のより意味が近いアイコンを選ぶ余地が残っています。

## 作図ツールの識別性評価

作図ツールはCanvas上の線種自体では区別されています。移動は実線・2px、パスは点線・3px、ドリブルはジグザグ線で描画され、いずれも矢印の終端を持ちます。従って、作図済みの内容よりも、**ツールを選ぶ前のツールバー**が主な問題箇所です。

| 操作 | 現在のアイコン | 問題 | 推奨アイコン | 推奨理由 | 優先度 |
|---|---|---|---|---|---|
| 選手移動 | `ti-arrow-right` | 普通の右矢印で、移動経路・任意方向を表しにくい | `ti-route` | 経路という意味と形状を持ち、他の線種と区別できる | 高 |
| パス | `ti-dots` | 三点リーダーに見え、方向・送球の情報がない | `ti-arrow-right-dashed` | 点線と矢印を同時に示し、Canvas上の表現とも一致する | **最優先** |
| ドリブル | `ti-activity` | 心電図・活動量に見え、ボール運びの連想が弱い | `ti-arrow-zig-zag` | ジグザグ動線を直接表し、Canvas上の描画と整合する | **最優先** |
| コーン | `ti-caret-up` | 小三角形で、上向き・展開などとも混同する | `ti-cone` | 練習コーンの実形状に近い | 高 |
| ラダー | `ti-menu-2` | メニュー（ハンバーガー）と読める | `ti-ladder` | 練習ラダーそのものを表す | 高 |
| ミニゴール | カスタムSVGマスク | Tablerに専用形状がない | 現状維持 | チーム固有／戦術固有の図形としてカスタムSVGが妥当 | 維持 |
| ボール | `ti-ball-football` | 問題なし | 現状維持 | サッカー固有で誤認しにくい | 維持 |
| マーカー／円エリア | `ti-circle` | 円の意味が重なるが、ラベルがあれば判断可能 | 現状維持＋ラベル常時表示 | 形状自体は正しいため文脈の補強で解決 | 中 |

### 根本原因

現在のツールドックは幅50px（スマートフォンでは44px）で、各ボタンは38px四方です。`.c-tool-dock__label`は通常時に`display: none`となり、**選択中のボタンだけ**ラベルが表示されます。説明ツールチップはホバー時のみで、スマートフォンのタップ操作では選択前の補助情報になりません。したがって、アイコンを交換しても、表示の仕組みを改善しない限り学習コストが残ります。

## 推奨する実装順序

| フェーズ | 内容 | 変更対象 | 完了条件 |
|---|---|---|---|
| D1 | 誤認しやすい4種類を交換 | `index.html` の作図ツールドック | パス＝点線矢印、ドリブル＝ジグザグ矢印、コーン＝コーン、ラダー＝ラダーとして表示される |
| D2 | 常時ラベルを導入 | `CSS/drawing.css` | 未選択時でも「移動／パス／ドリブル／コーン／ラダー」が読める。タッチ端末でホバーに依存しない |
| D3 | 選択状態の二重符号化 | `CSS/drawing.css`、`drawing.js` | 色だけでなく、選択中のラベル、背景、`aria-pressed`で状態を識別できる |
| D4 | Tablerのサッカー語彙を戦術導線へ展開 | 戦術一覧、配置・チームカラーUI | 戦術入口に`ti-soccer-field`、配置関連に`ti-shirt-sport`を使い、意味の近いアイコンを優先する |
| D5 | 契約テストを追加 | `tests/` | 作図ツールの各`data-tool`が指定アイコン・常時ラベル・アクセシブルな名称を持つことを自動検証する |

D1〜D3は同時に実施することを推奨します。アイコンだけを入れ替えるより、**意味が近い形状、常時見える日本語ラベル、選択状態の非色彩的な表現**をセットで導入する方が、片手操作中の選択ミスを減らせます。

## 参照と確認方法

監査用の比較プレビューでは、現在の作図アイコンと候補を36pxで並べて確認できます。`reports/tabler-soccer-icon-preview-v13083.html` をブラウザで開いてください。

今回のコード監査では、主に `index.html` の作図ツールドック、`CSS/drawing.css` の表示規則、`pitch-renderer.js` のCanvas描画関数、TablerのローカルWebfont CSSを確認しました。
