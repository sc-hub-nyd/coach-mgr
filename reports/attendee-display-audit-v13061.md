# 参加者表示の横断監査

**対象ブランチ:** `feat/label-shape-unification`  
**監査日:** 2026-08-19  
**基準部品:** `c-attendee-list`、`c-attendee-chip`、`c-attendee-chip__number`、`c-attendee-chip__name`

## 監査基準

練習一覧の参加者表示を正本とする。参加者を氏名・背番号付きで一覧表示する画面は、共通の参加者リストとチップを利用し、自然幅のチップ、背番号の正円マーカー、折返し、同一の背景色・文字色を満たすことを合格条件とした。

編集操作を伴う招集・出欠名簿は、チェックボックスと状態選択を提供するため、`c-roster-list`／`c-roster-row--attendance` を使用する。この操作UIは参加者チップ表示とは別責務であり、監査上の意図的な例外とした。

| 画面・領域 | 表示目的 | 現在の部品 | 判定 | 補足 |
|---|---|---|---|---|
| 練習一覧・展開詳細 | 参加選手の閲覧 | `c-attendee-list` + `c-attendee-chip` | 統一済み | 正本デザイン。 |
| 試合一覧・参加者展開 | 参加選手の閲覧 | `c-attendee-list` + `c-attendee-chip` | 統一済み | 試合カードの子孫`span`を一括圧縮していた規則を除去し、少人数でも自然幅、複数人数では折返しを維持する。 |
| 試合詳細・保護者表示 | 参加選手の閲覧 | `c-attendee-list` + `c-attendee-chip` | 統一済み | 外枠の詳細アコーディオンは画面構造上の差異だが、参加者チップそのものは共通。 |
| 試合詳細・コーチ表示 | 招集・出欠編集 | `c-roster-list` + `c-roster-row--attendance` | 意図的例外 | 編集要素を含む業務UI。チップ表示対象外。 |
| 試合作成・編集 | 招集・出欠編集 | `c-roster-list` | 意図的例外 | 保存前の入力UI。 |
| 練習作成・編集 | 招集・出欠編集 | `c-roster-list` | 意図的例外 | 保存前の入力UI。 |
| 選手詳細（育成ノート） | 個人の参加率指標 | 指標・メトリクス | 対象外 | 他選手を参加者一覧として表示しない。 |
| ダッシュボード・ランキング | 個人の集計順位 | `c-data-list` | 対象外 | 参加率を含む集計表示であり、イベント参加者一覧ではない。 |
| ライブラリ・戦術・イベント概要 | 件数の概要 | テキストメタ情報 | 対象外 | 参加者個人を並べて表示しない。 |

## 回帰防止

P35に以下の契約を追加した。

| 契約 | 保証内容 |
|---|---|
| 共通チップ構造 | 試合・練習の両ソースが`c-attendee-list`／`c-attendee-chip`と各要素を利用する。 |
| 少人数表示 | `c-attendee-chip`が`flex: 0 0 auto`で自然幅を保つ。 |
| 複数人数表示 | `c-attendee-list`が`flex-wrap: wrap`で折り返す。 |
| 背番号マーカー | `c-attendee-chip__number`が`aspect-ratio: 1`で正円を保つ。 |
| 試合一覧の干渉防止 | `.match-card-header span`および`.match-card-header>div:first-child`のような子孫を一括圧縮する規則を禁止する。 |
| 旧規則の再導入防止 | 旧`u-ext-54`〜`u-ext-56`および`u-ext-140`を禁止する。 |

## 結論

参加選手を閲覧用チップとして表示するすべての画面は共通部品へ統一された。出欠を編集する名簿と、参加率のみを示す個人・集計画面は、用途が異なるためチップ統一の対象外である。

今後、参加者を氏名・背番号付きで新たに表示する機能を追加する場合は、画面固有のバッジやインライン装飾を追加せず、本監査基準の共通参加者部品を使用する。
